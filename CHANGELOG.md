# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.4.1] - 2025-12-11

### Добавлено
- Два тестовых стримера (8h и 30h) в веб-интерфейсе для наглядной проверки прогресс-бара Watch Time.

### Исправлено
- Прогресс-бар Watch Time теперь использует изолированные классы, корректно отображает заполнение и переключается в золотой цвет при достижении 100% ширины.

## [0.3.5] - 2025-12-10

### Исправлено
- Исправлено дублирование событий `claim-available` - теперь перед попыткой собрать бонус проверяется его доступность для конкретного стримера
- Улучшен расчет `initialChannelPoints` из WebSocket событий - теперь правильно вычитаются заработанные баллы при первом событии
- Исправлен расчет `pointsEarned` - теперь корректно вычисляется даже если `initialChannelPoints` не был установлен сразу

### Изменено
- События `minute-watched` больше не отображаются в веб-интерфейсе (технические события скрыты от пользователя)
- Улучшена обработка ошибок GraphQL - добавлены fallback механизмы для `PersistedQueryNotFound` ошибок
- Улучшено логирование - некритичные ошибки логируются только в verbose режиме

### Добавлено
- Добавлен полный набор тестов (55 тестов) с использованием Vitest:
  - Тесты для получения и расчета баллов
  - Тесты для обработки claim событий
  - Тесты для GraphQL клиента с fallback механизмами
  - Интеграционные тесты
- Добавлена иконка favicon для веб-интерфейса
- Добавлен GitHub Actions workflow для автоматического запуска тестов
- Добавлены папки `statistics/` и `test-statistics/` в `.gitignore`

### Технические улучшения
- Улучшена обработка ошибок `PersistedQueryNotFound` для операций `ChannelPointsContext` и `VideoPlayerStreamInfoOverlayChannel`
- Добавлены fallback механизмы для получения channel ID через Helix API
- Улучшена обработка ошибок `Cannot query field` для некритичных операций

## [0.3.4] - 2025-12-09

### Исправлено
- Исправлен расчет заработанных баллов - теперь используется `channelPoints` вместо `lastChannelPoints`

### Добавлено
- Добавлен веб-интерфейс для мониторинга и статистики
- Добавлена поддержка сохранения статистики в файл
