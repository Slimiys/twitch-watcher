## Быстрый старт

1. Прочитайте [README.md](../README.md) в корне проекта
2. Настройте параметры в dashboard → **«Конфиг бота»** или в `config.json`
3. Для Android используйте [ANDROID_SETUP.md](ANDROID_SETUP.md)
