# План развития проекта Twitch Watcher

Документ содержит планы по улучшению и развитию проекта, отсортированные по приоритету выполнения.

## 🔴 Высокий приоритет

### 1. Сохранение статистики и истории
**Описание:** Сохранение статистики просмотра в файл для последующего анализа.

**Задачи:**
- [x] Создать модуль для сохранения статистики (JSON/CSV/SQLite)
- [x] Сохранять каждую сессию просмотра с метаданными:
  - Имя стримера
  - Время начала и окончания просмотра
  - Начальные и конечные баллы канала
  - Количество заработанных баллов
  - Статус (успешно/прервано)
- [x] Реализовать агрегированную статистику (за день/неделю/месяц)
- [x] Автоматическая ротация старых записей

**Преимущества:**
- Возможность анализа эффективности просмотра
- Отслеживание трендов по стримерам
- История заработанных баллов

- [ ] Валидировать все переменные окружения:

  - Логические параметры
- [ ] Понятные сообщения об ошибках валидации
- [ ] Предупреждения о неиспользуемых параметрах

**Преимущества:**
- Раннее обнаружение проблем конфигурации
- Меньше ошибок во время выполнения
- Улучшенный UX при настройке
