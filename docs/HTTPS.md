# HTTPS для дашборда

Опциональный HTTPS для веб-интерфейса (порт `WEB_SERVER_PORT`, обычно 3001). Нужен, чтобы в браузере работали **уведомления ОС** при открытии дашборда по IP в локальной сети (`https://192.168.x.x:3001`).

Health check остаётся на HTTP (`HEALTH_CHECK_PORT`, обычно 3000).

## Быстрый старт

1. В **dashboard → «Конфиг бота»** или в `config.json` → `app`:

```json
{
  "app": {
    "WEB_SERVER_HTTPS": "true",
    "WEB_SERVER_PORT": "3001",
    "SSL_EXTRA_SANS": "192.168.1.145"
  }
}
```

`SSL_EXTRA_SANS` — IP устройства в LAN (можно несколько через запятую). Без этого браузер может ругаться на несовпадение имени.

2. Установите **openssl** (Termux: `pkg install openssl`).

3. При первом запуске сертификат создаётся в `./certs/` автоматически. Или вручную:

```bash
npm run certs:generate
```

4. Перезапустите приложение: `npm run build && npm start`.

5. В браузере откройте `https://192.168.1.145:3001`, примите предупреждение о самоподписанном сертификате.

6. В дашборде: Settings → уведомления ОС → сохранить и разрешить в браузере.

## Параметры (секция `app` в config.json)

| Ключ | Описание |
|------|----------|
| `WEB_SERVER_HTTPS` | `true` / `1` — включить HTTPS |
| `SSL_DIR` | Каталог сертификатов (по умолчанию `./certs`) |
| `SSL_CERT_PATH` | Путь к `server.crt` |
| `SSL_KEY_PATH` | Путь к `server.key` |
| `SSL_EXTRA_SANS` | Доп. SAN: IP и DNS через запятую |
| `SSL_CERT_CN` | Common Name (по умолчанию `twitch-watcher`) |

Скрипт `npm run certs:generate` может дополнительно читать те же переменные из локального `.env` — это только для генерации сертификатов, не для запуска бота.

## Доверенный сертификат (опционально)

Для ПК без предупреждения используйте [mkcert](https://github.com/FiloSottile/mkcert): создайте сертификат для IP, укажите пути в `SSL_CERT_PATH` и `SSL_KEY_PATH`.

## SSH-туннель без HTTPS

Альтернатива: `ssh -L 3001:127.0.0.1:3001 ...` и `http://localhost:3001` — уведомления ОС тоже работают.
