# Подключение к Android по WiFi через SSH

## Шаг 1: На Android устройстве (Termux)

### Установка SSH сервера:

```bash
# Обновляем пакеты
pkg update && pkg upgrade -y

# Устанавливаем openssh
pkg install openssh

# Устанавливаем пароль для пользователя (важно!)
passwd
# Введите пароль (запомните его!)

# Проверяем и исправляем права доступа
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# Запускаем SSH сервер
sshd
```

### Решение проблемы "cannot bind netlink socket: Permission denied"

Если вы видите эту ошибку, попробуйте следующие решения:

**Решение 1: Проверьте разрешения Termux**

1. На Android устройстве:
   - Настройки → Приложения → Termux → Разрешения
   - Убедитесь, что включены все необходимые разрешения
   - Особенно важно: "Хранилище" и "Сеть"

2. Перезапустите Termux после изменения разрешений

**Решение 2: Используйте альтернативный метод запуска**

```bash
# Остановите все процессы SSH (если запущены)
pkill sshd

# Проверьте конфигурацию SSH
sshd -t

# Если конфигурация правильная, попробуйте запустить с явным указанием конфига:
sshd -f $PREFIX/etc/ssh/sshd_config

# Или запустите в debug режиме для диагностики:
sshd -d -f $PREFIX/etc/ssh/sshd_config
```

**Решение 3: Проверьте и исправьте конфигурацию SSH**

```bash
# Отредактируйте конфигурацию SSH:
nano $PREFIX/etc/ssh/sshd_config

# Убедитесь, что следующие строки установлены правильно:
# Port 8022
# PermitRootLogin no
# PasswordAuthentication yes
# PubkeyAuthentication yes

# Сохраните файл (Ctrl+O, Enter, Ctrl+X)

# Проверьте синтаксис конфигурации:
sshd -t

# Если ошибок нет, запустите SSH:
sshd -f $PREFIX/etc/ssh/sshd_config
```

**Решение 4: Используйте dropbear (альтернативный SSH сервер)**

Если openssh не работает, можно использовать dropbear:

```bash
# Установите dropbear
pkg install dropbear

# Запустите dropbear на порту 8022:
dropbear -p 8022

# Для постоянного запуска создайте скрипт:
echo 'dropbear -p 8022' > ~/.termux/boot/start-dropbear.sh
chmod +x ~/.termux/boot/start-dropbear.sh
```

**Решение 5: Проверьте, не занят ли порт**

```bash
# Проверьте, не используется ли порт 8022:
netstat -tuln | grep 8022

# Если порт занят, найдите процесс:
lsof -i :8022
# Или:
fuser 8022/tcp

# Остановите процесс, если нужно:
kill <PID>
```

### Узнайте IP адрес Android устройства:

```bash
# В Termux выполните:
ifconfig

# Или:
ip addr show

# Найдите IP адрес в локальной сети
# Обычно это что-то вроде: 192.168.1.100 или 10.0.0.50
# Ищите строку с "inet" и адресом, начинающимся с 192.168 или 10.
```

**Важно:** Запишите IP адрес! Он понадобится для подключения.

### Проверка, что SSH работает:

```bash
# Проверьте, что SSH сервер запущен:
ps aux | grep sshd

# Должна быть строка с /usr/bin/sshd
```

## Шаг 2: На компьютере (Windows)

### Проверка подключения:

```powershell
# Проверьте, что Android устройство доступно в сети:
ping <IP_адрес_Android>
# Например: ping 192.168.1.100
```

### Подключение через SSH:

Если у вас установлен OpenSSH клиент (в Windows 10/11 обычно есть):

```powershell
# Подключение:
ssh -p 8022 <IP_адрес_Android>
# Например: ssh -p 8022 192.168.1.100

# Порт 8022 - стандартный порт SSH в Termux
```

Если OpenSSH не установлен, можно использовать:
- **PuTTY** (скачать с https://www.putty.org/)
- **Windows Terminal** с OpenSSH
- **WSL** (Windows Subsystem for Linux)

### Настройка PuTTY:

1. Откройте PuTTY
2. В поле "Host Name" введите: `<IP_адрес_Android>`
3. В поле "Port" введите: `8022`
4. Connection type: SSH
5. Нажмите "Open"
6. При первом подключении подтвердите ключ сервера
7. Введите имя пользователя (обычно это имя пользователя в Termux)
8. Введите пароль, который вы установили командой `passwd`

## Шаг 3: После подключения

После успешного подключения вы сможете:

```bash
# Выполнять команды на Android устройстве
cd ~/twitch_watcher
npm start

# Просматривать логи
tail -f logs/app.log

# Управлять приложением
# Остановить: Ctrl+C
# Запустить в фоне: nohup npm start &
```

## Решение проблем

### Проблема: "Connection refused" или "Connection timed out"

1. **Проверьте, что SSH сервер запущен на Android:**
   ```bash
   # В Termux на Android:
   ps aux | grep sshd
   # Если нет процесса, запустите: sshd
   ```

2. **Проверьте, что устройства в одной сети WiFi:**
   - Android и компьютер должны быть подключены к одной WiFi сети
   - Проверьте IP адреса - они должны быть в одном диапазоне (например, оба 192.168.1.x)

3. **Проверьте файрвол на Android:**
   - Настройки → Безопасность → Файрвол
   - Убедитесь, что Termux имеет разрешение на сетевые подключения

4. **Проверьте, что порт 8022 открыт:**
   ```bash
   # На Android в Termux:
   netstat -tuln | grep 8022
   # Должна быть строка: tcp 0.0.0.0:8022
   ```

### Проблема: "Permission denied"

1. **Проверьте пароль:**
   - Убедитесь, что вы вводите правильный пароль
   - Пароль устанавливается командой `passwd` в Termux

2. **Проверьте права доступа:**
   ```bash
   # На Android в Termux:
   ls -la ~/.ssh
   # Убедитесь, что файлы имеют правильные права
   chmod 700 ~/.ssh
   chmod 600 ~/.ssh/authorized_keys
   ```

### Проблема: Не могу найти IP адрес

1. **Используйте альтернативные команды:**
   ```bash
   # В Termux:
   ip route get 8.8.8.8 | awk '{print $7}'
   
   # Или:
   hostname -I
   ```

2. **Проверьте через настройки Android:**
   - Настройки → О телефоне → Статус → IP адрес
   - Или: Настройки → WiFi → Нажмите на подключенную сеть → IP адрес

## Автозапуск SSH при загрузке Termux

Чтобы SSH сервер запускался автоматически:

```bash
# Установите termux-boot:
pkg install termux-boot

# Создайте скрипт автозапуска:
mkdir -p ~/.termux/boot
nano ~/.termux/boot/start-ssh.sh
```

Добавьте в файл:
```bash
#!/data/data/com.termux/files/usr/bin/bash
sshd
```

Сделайте файл исполняемым:
```bash
chmod +x ~/.termux/boot/start-ssh.sh
```

Теперь SSH будет запускаться автоматически при загрузке Termux.
