# План развития веб-интерфейса Twitch Watcher

Документ содержит детальный план улучшений веб-интерфейса (dashboard), отсортированный по приоритету выполнения.

## 🔴 Высокий приоритет

### 1. Поиск и фильтрация стримеров
**Описание:** Улучшение навигации и поиска в таблице стримеров.

**Задачи:**
- [ ] Добавить поле поиска по имени стримера
- [ ] Реализовать фильтрацию по статусу (онлайн/офлайн)
- [ ] Добавить фильтр по диапазону баллов
- [ ] Сохранение состояния фильтров в localStorage
- [ ] Подсветка результатов поиска

**Преимущества:**
- Быстрый поиск нужного стримера
- Удобная фильтрация больших списков
- Улучшенный UX при работе с множеством стримеров

**Оценка:** 2-3 часа

**Описание:** Интерактивная сортировка по всем колонкам таблицы.

- [ ] Визуальные индикаторы направления сортировки (↑/↓)

- [ ] Множественная сортировка (опционально)
- [ ] Сброс сортировки к умолчанию

**Преимущества:**
- Удобная организация данных
- Быстрый поиск лидеров по баллам/времени
- Гибкая настройка отображения

**Оценка:** 2 часа
