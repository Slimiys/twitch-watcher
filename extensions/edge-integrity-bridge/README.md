# Twitch Watcher — Integrity Bridge (Edge)

Расширение перехватывает заголовок `Client-Integrity` из запросов к `https://gql.twitch.tv` и отправляет его в локальный бот Twitch Watcher.

## Установка в Edge

1. Соберите и запустите бот (`npm run build`, затем запуск с dashboard на порту 3001 по умолчанию).
2. Откройте `edge://extensions/`.
3. Включите **Режим разработчика**.
4. **Загрузить распакованное** → выберите папку `extensions/edge-integrity-bridge`.
5. Откройте popup расширения (иконка расширения на панели Edge), укажите URL бота (`http://127.0.0.1:3001`) и нажмите **Проверить бота**. API-ключ подтягивается автоматически с открытого dashboard (если задан в «Конфиг бота»).

После обновления файлов расширения на `edge://extensions/` нажмите **Обновить** у карточки Integrity Bridge.

На дашборде бота (секция **Статус бота**) клик по карточке **Client Integrity** отправляет запрос в расширение: обновляется вкладка twitch.tv, токен передаётся в бот.

## Уведомления о стримах (v1.1)

Расширение может показывать **системные уведомления Windows** при `stream-up` / `stream-down` с локального бота — **дашборд может быть закрыт**.

1. В popup нажмите **«Уведомления: выкл»** → переключится в **вкл** (на иконке расширения badge `ON`).
2. Горячая клавиша по умолчанию: **Ctrl+Shift+Y** (настраивается в `edge://extensions/shortcuts`).
3. Кнопка **«Тест уведомления»** в popup — проверка системных уведомлений Windows без ожидания stream-up/down.
4. Бот должен быть запущен; URL — в popup. API-ключ синхронизируется с dashboard автоматически.

Источник событий: `GET /api/events/stream` (SSE) + опрос раз в минуту как fallback. Если задан `WEB_DASHBOARD_API_KEY`, откройте dashboard и сохраните «Конфиг бота» — ключ передастся в расширение.

## Как это работает

1. Откройте [twitch.tv](https://www.twitch.tv) в Edge (тот же профиль, где установлено расширение).
2. Перейдите на любой канал или обновите страницу — пойдут gql-запросы.
3. Расширение отправит в `POST /api/integrity/capture`: `Client-Integrity`, `Client-Version`, `Client-Session-Id`, `X-Device-Id` (из заголовков gql).
4. Бот сохранит токен в `config.json` (если включено **Сохранять integrity**) и применит без перезапуска.

## Настройки бота

| Переменная | Описание |
|------------|----------|
| `INTEGRITY_BRIDGE_ENABLED` | `false` — отключить приём от расширения |
| `WEB_DASHBOARD_API_KEY` | Если задан — сохраните в dashboard → «Конфиг бота»; ключ синхронизируется с расширением |
| `TWITCH_INTEGRITY_AUTO_PERSIST` | Сохранение в config (по умолчанию вкл.) |
